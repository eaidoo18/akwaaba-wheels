# Akwaaba Wheels

Single-page car rental website for a Ghanaian brand. Plain HTML and CSS, no build step.

## Run locally
Open `index.html` in a browser.

## Images
Every car image is a file in `assets/` (illustrations by default). To use real photos, add them to `assets/` and update the matching `src` in `index.html`.

## Deploy with GitHub Pages
1. Push this folder to a new GitHub repository.
2. Go to Settings > Pages, choose the `main` branch and `/ (root)`, then save.
3. Your site will be live at `https://<your-username>.github.io/<repo-name>/`.
